### What?
Floppy is a blazingly fast file server. The main goal of this file server is to be fast on slow networks

### Why?
I use [copyparty](https://github.com/9001/copyparty) extensively everyday, but it does so many things which I do not use. I travel often, so I want a fast fileserver which:
  a. Does adaptive bitrate video streaming (HLS, in pipeline)
  b. Has no bloatware UI and with no dependencies (just plain HTML, CSS, JS)
  c. Has a single binary which is of few MBs
